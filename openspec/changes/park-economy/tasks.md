# Tasks

Conventions for every task below. C# work starts by consulting the `4dotnet-csharp-style-guide` MCP server (`search_documents` for the topic of the task) and follows it; data members are properties, never public fields; every behaviour task is test-first (write the failing xUnit v3 test named after the rule, see it fail, implement, see it pass); no FluentAssertions; no magic numbers (constants in `Economy/Domain/EconomyParameters.cs` with a one-line in-game meaning, derivations in `docs/economy/01-park-economy.md`); no `double`, `float` or `DateTime.Now` in the Economy domain; amounts are `Money` (cents); handlers implement `ExecuteAsync`, endpoints contain no business logic and never touch `Api/Program.cs`; DTOs under `Economy.Abstractions/DataTransferObjects/<Feature>/` (use the `dto-organization` skill); Angular work consults the `primeng` MCP server before any PrimeNG component and follows `src/FourDotnet.BoogaBooster.App/.claude/CLAUDE.md`. Backend paths are relative to `src/`; "module" is `Economy/FourDotnet.BoogaBooster.Economy`, "abstractions" is `Economy/FourDotnet.BoogaBooster.Economy.Abstractions`, "tests" is `Tests/FourDotnet.BoogaBooster.Economy.Tests`, "sim" is `Simulation/FourDotnet.BoogaBooster.Simulation`, "sim-abs" is `Simulation/FourDotnet.BoogaBooster.Simulation.Abstractions`, "harness" is `Tools/FourDotnet.BoogaBooster.Economy.BalanceHarness`, "app" is `FourDotnet.BoogaBooster.App/src/app`. Run `dotnet test Tests/FourDotnet.BoogaBooster.Economy.Tests` from `src/` after every backend group and `npm test` from `FourDotnet.BoogaBooster.App` after every frontend group. Legal rule: specify behaviour in our own words and numbers; never copy code, strings, assets or names from OpenRCT2 or Roller Coaster Tycoon.
