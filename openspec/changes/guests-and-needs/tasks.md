# Tasks

Conventions for every task below. C# work starts by consulting the `4dotnet-csharp-style-guide` MCP server (`search_documents` for the topic of the task) and follows it; data members are properties, never public fields; every behaviour task is test-first (write the failing xUnit v3 test named after the rule, see it fail, implement, see it pass); no FluentAssertions; no magic numbers (constants in `Simulation/Guests/GuestParameters.cs` with a one-line in-game meaning, derivations in `docs/simulation/guests-and-needs.md`); no `System.Random`, wall clock, `Dictionary` iteration or floating-point `Pow/Exp` in guest systems; Angular work consults the `primeng` MCP server before any PrimeNG component and follows `src/FourDotnet.BoogaBooster.App/.claude/CLAUDE.md`. Backend paths are relative to `src/`; "module" is `Simulation/FourDotnet.BoogaBooster.Simulation`, "abstractions" is `Simulation/FourDotnet.BoogaBooster.Simulation.Abstractions`, "tests" is `Tests/FourDotnet.BoogaBooster.Simulation.Tests`, "bench" is `Benchmarks/FourDotnet.BoogaBooster.Simulation.Benchmarks`, "app" is `FourDotnet.BoogaBooster.App/src/app`. Run `dotnet test Tests/FourDotnet.BoogaBooster.Simulation.Tests` from `src/` after every backend group and `npm test` from `FourDotnet.BoogaBooster.App` after every frontend group. Legal rule: specify behaviour in our own words and numbers; never copy code, strings, assets or names from OpenRCT2 or Roller Coaster Tycoon.
