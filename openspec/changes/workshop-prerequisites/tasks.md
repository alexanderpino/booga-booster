Tags: **[no-tools]** needs only Node and the OpenSpec CLI (everything in groups 1 to 4 and 8). **[needs-network]** needs access to official vendor documentation or upstream repositories (read, never from memory). **[needs-blender]**, **[needs-krita]** need the application installed on the apply machine; if absent, stop at that task, leave it unchecked and report. Paths are relative to the repo root; doctor code lives in `tools/doctor/` (`DR/`), tests run with `node --test DR/test`. No C# and no Angular code is touched, so the style-guide and PrimeNG MCP steps do not apply. Hard rules for every doctor task: dependency-free (only `node:` built-ins), read-only probes, no secret ever printed, every command goes through the allow-list in `DR/lib/probes.mjs`, no magic numbers (timeouts and truncation lengths are named constants in `DR/lib/constants.mjs`). Apply in a worktree via the `git-change-workflow` skill (branch `feature/workshop-prerequisites`), logical Conventional Commits, PR into `main`, never merged by the agent.
