# Tasks

Conventions for every group: write the failing test first and name the rule in the test name; any C# task starts with "consult the `4dotnet-csharp-style-guide` MCP server first" (once per group is enough, re-consult when the folder layout changes); backend tests go in `src/Tests/FourDotnet.BoogaBooster.Simulation.Tests/Park/` (xUnit v3 + Moq + Bogus, no FluentAssertions); properties, never public fields; every number is a named constant in `ParkTuning` with its derivation in `docs/park/01-park-world-grid.md`; Angular code is zoneless, signals, OnPush, PrimeNG for new UI, Vitest + axe-core. Scoped commands: `dotnet test src/Tests/FourDotnet.BoogaBooster.Simulation.Tests` and, in `src/FourDotnet.BoogaBooster.App`, `npm test`.
