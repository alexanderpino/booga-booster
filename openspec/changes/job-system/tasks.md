# Tasks

Conventions for every group: C# lives under `src/Simulation/FourDotnet.BoogaBooster.Simulation/Jobs/` (implementation) and `src/Simulation/FourDotnet.BoogaBooster.Simulation.Abstractions/Jobs/` (public contracts); tests under `src/Tests/FourDotnet.BoogaBooster.Simulation.Tests/Jobs/` (xUnit v3, Moq, Bogus, `Assert`; no FluentAssertions). Properties, never public fields. Write the failing test first in each task, then the code. No magic numbers: tuning constants go in a `JobSystemDefaults` static class in the module with the rationale in `docs/simulation/job-system.md`. Build and test scope: `dotnet test src/Tests/FourDotnet.BoogaBooster.Simulation.Tests` from `src/`; run the full solution only in group 13.
